使用说明

查询操作、服务器部署、服务关闭，以及不同系统上的端口与进程排查方法。

域名查询

  1. 在“查询”页输入域名或 URL，每行一个。
  2. 选择查询模式和超时时间后开始查询；运行期间可暂停、继续或取消。
  3. 结果展示可在“状态刷新”和“逐条加入”之间即时切换；“未知（建议重查）”可使用“重新查询异常/未知”。
  4. 拖动表头分隔线调整列宽；点击普通单元格复制内容。

服务器部署

生产环境推荐使用 Nginx + Gunicorn + systemd：Nginx 提供 HTTPS 与访问认证，Gunicorn 仅监听 127.0.0.1:5000。

当前任务状态保存在进程内存中，Gunicorn 必须保持单 worker；不要启用多 worker、多实例或把 5000 端口直接暴露到公网。

Python 环境推荐使用 uv 管理项目内的 .venv；本项目不依赖 Conda 二进制生态，无需额外安装 Miniforge。

宝塔用户只让面板管理 Nginx、域名和证书，Gunicorn 仍交给 systemd；不要同时通过宝塔 Python 项目与 systemd 启动。

应用没有登录权限系统，公网入口至少启用 Nginx Basic Auth。宝塔开启反向代理后需确认访问限制仍实际生效。完整步骤见 docs/DEPLOYMENT_NGINX.md。

网页不提供关闭服务入口。请回到启动服务的终端按 Ctrl+C，或使用下方对应系统的进程管理命令。

命令行排查与停止

前台运行时优先回到启动服务的终端按 Ctrl+C。若终端已丢失，可按系统查找监听 5000 端口的进程。

Windows PowerShell

1. 查询端口
Get-NetTCPConnection -LocalPort 5000 -State Listen
2. 确认进程
Get-Process -Id <PID>
3. 停止服务
Stop-Process -Id <PID>
旧版 Windows 查询
netstat -ano | findstr :5000
旧版 Windows 停止
taskkill /PID <PID>

macOS

1. 查询端口
lsof -nP -iTCP:5000 -sTCP:LISTEN
2. 确认进程
ps -p <PID> -o pid,command
3. 正常停止
kill <PID>
4. 强制停止（仅在无响应时）
kill -9 <PID>

Linux

1. 查询端口
ss -ltnp 'sport = :5000'
2. 确认进程
ps -p <PID> -o pid,cmd
3. 正常停止
kill <PID>
备用端口查询
lsof -nP -iTCP:5000 -sTCP:LISTEN
