# Agent 接手与交接

## 接手检查

1. 读 `AGENTS.md` 与 `spec/README.md`，只加载任务对应专题。
2. 查看用户最新请求、`git status --short`、相关文件 diff 和最近测试结果。
3. 明确哪些改动已存在、哪些由当前 Agent 新增；不要假定脏工作区可清理。
4. 确认测试不会触碰真实 `data/`，前端默认不截图。

## 交接记录应包含

- 当前目标和用户明确约束。
- 已完成的行为及关键实现位置。
- 未完成步骤与下一条可直接执行的命令。
- 已运行的验证、测试数量和结果；未运行项及原因。
- 工作区已有改动、真实数据、运行服务等需要保护的现场状态。
- 已知风险、复现条件和仍需用户决定的问题。

不要用大段思考过程代替事实。交接应让下一位 Agent 能在数分钟内定位代码并继续执行。

## 完成标准

- 请求中的功能已实现，回归用例覆盖关键失败路径。
- 全量 pytest、ruff 与 `git diff --check` 通过。
- API、架构、README、规格和 changelog 已按改动范围同步。
- 最终回复说明结果、验证和任何剩余风险，不要求用户阅读隐藏的工作日志。
