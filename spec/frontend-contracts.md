# 前端契约

## 基础约束

- 前端为单文件 `templates/index.html`，原生 HTML/CSS/JS，无构建步骤。
- 中文界面；API 字段与后端保持兼容。Tab 通过 `data-tab` 定位，不依赖浏览器全局 `event`。
- 查询区提供“执着模式”开关：勾选后任务请求带 `persistent=true`，开关偏好保存在本地；
  失败或超时的域名会自动重试，单次超时逐轮放宽，轮数上限取配置项 `persistent_max_rounds`。
  状态接口返回 `persistent_round` / `persistent_retrying` 时，进度区显示“执着模式第 N/M 轮，重试 X 个域名”。
- 域名默认点击打开 `https://域名`；重查、详细结果、复制三个行内操作集中在表格最右侧固定的“操作”列，
  以图标按钮呈现并保留 `title` 与 `aria-label`。
- 结果表两个筛选项分别标注为“查询状态”和“域名状态”，两者互相独立；`not_registered` 是查询状态值，在域名状态筛选中为“不适用”。
  筛选项默认收起：结果板块下方工具条中的「筛选器」按钮打开弹窗进行筛选，按钮角标显示已启用的筛选项数量，
  表格外的“共 N 条 / 筛选出 M 条”提示始终可见；弹窗内提供「重置筛选」与「完成」，Esc 关闭。
- 查询进度属于结果板块；处理中同时提供滚动不丢失的固定状态提示，结束后显示最终耗时。
- 查询模式包含不限流、标准、快速和简略快速；简略快速的提示需明确只执行一次注册查询和一次 DNS 检查，并跳过 HTTP 探测与自动复查。
- 排队占位行的查询时间与查询耗时保持空白，不显示伪造的 `0 秒` 或占位时间。
- 复用最近成功结果的行使状态列显示“查询成功 · 复用”，查询来源列显示“本地缓存”；实时联网行显示
  “在线查询”，排队/查询中显示“待查询”。详细结果的“结果来源”说明具体来源，
  `query_time`/查询耗时保留原始值，不伪装成本次联网查询。
- 查询区提供“忽略缓存”复选框：默认不勾选，提交时传 `ignore_cache`；复用窗口在配置面板按
  「小时 + 分钟」自定义（默认 1 小时，上限 24 小时，两项都填 0 即关闭），
  勾选后本任务全部联网查询，重查始终强制联网。
- 暂停/继续与终止控件属于结果板块，并随处理中固定状态提示保持可操作；输入区不重复放置任务控制。
- 暂停期间前端只轮询任务状态，不拉取日志/结果；恢复后再补齐增量日志。已发出的网络请求可以完成，
  但日志区不得持续刷新。
- 当前任务 ID 与查询参数保存在本地，刷新页面后恢复查询/暂停进度；任务已丢失时回填历史域名。
  历史列表区分“已完成 / 处理中 / 已中断”，无结果的已中断记录提供“回填域名”而不是“查看”。
- 暂停或终止任务时，仅尚未完成的结果行在状态列显示“已暂停”或“已终止”；已成功查询的行保持最终状态。
  恢复任务后，暂停行回到暂停前的排队或查询状态。
- 失败状态必须在表格状态列直接显示可判读类别（超时、配额、网络解析、网络连接、空响应或解析错误），
  备注列和详细结果继续保留完整原始错误。
- 解析列默认紧跟注册状态；查询来源列默认紧跟查询耗时，显示“本地缓存 / 在线查询 / 待查询”并支持排序；
  复选框与序号列固定（序号列紧跟复选框，按当前筛选/排序后的展示顺序从 1 连续编号），
  操作列固定在末列，两者都不参与拖拽换序和列宽调整；其余结果列支持拖拽换序并按列标识持久化顺序和宽度。
- 操作列使用 `position: sticky; right: 0` 与不透明单元格背景，横向滚动时保持可见且与行悬停底色一致；
  只有右侧仍有被遮住的内容时才显示左侧分隔线与内阴影。
- 正在查询使用固定尺寸的行内加载动画，不得引起表格行高或列宽跳动。
- 结果展示支持“状态刷新”（全部域名占位并刷新单元格）和“逐条加入”（首次查询仅展示已有最终结果）模式；
  切换不重新提交任务，重查已有结果时逐条模式不隐藏旧行，偏好保存在本地。
- 详细结果展示后端返回的 `raw_response`，即 WHOIS 原始文本或 RDAP JSON；历史详情同样保留。
  该区块以带行号、JSON 语法高亮和「复制」按钮的代码块呈现，非 JSON 的 WHOIS 文本按纯文本带行号展示。
- 详细结果弹窗采用经典窗口布局：标题行（标题 + 关闭）固定，只有内容区滚动，关闭按钮始终可见。
- 运行日志显示连续行号（增量追加时行号不得重新从 1 开始），支持复制当前筛选结果；日志默认不占页面版面，
  由结果板块查询浮层上的「📜 日志」按钮以弹窗打开（弹窗内可切换级别、复制、按 Esc/遮罩/关闭按钮退出）。
- 查询结果仅在对应区块可见时出现在侧栏大纲；运行日志改为弹窗后不再有侧栏锚点。
- 筛选弹窗中的两个下拉在选项文案后显示实时条目数量，如「失败（3）」；数量按另一项筛选交叉统计，
  与该选项被选中后看到的行数一致。

## 侧栏和移动端

- 桌面侧栏支持左/右停靠与紧凑模式，偏好保存在 `localStorage`，颜色使用主题变量。
- `max-width: 1250px` 时显示汉堡按钮，侧栏变为从已保存方向滑入的抽屉，不继承桌面紧凑宽度。
- Tab 栏（`.tabs`）整条 `position: sticky` 吸顶常驻，页眉标题随内容滚走；吸顶栏内从左到右为
  汉堡按钮（窄屏）、Tab 列表、主题入口，`z-index` 低于弹窗与浮层。
- 颜色主题入口收在吸顶栏右侧：默认只有一枚显示当前主题的圆点按钮，点开才出现四色选择面板；
  选中后自动收起并写回本地偏好，支持点击外部与 Escape 关闭，键盘可完成全部操作。
- 窄屏页眉只保留产品名称与版本；汉堡按钮位于吸顶栏内，并随侧栏停靠方向排列到左端或右端，
  不得作为独立 fixed 元素覆盖页面。
- 页眉与工具栏都不重复展示当前查询平台，平台在配置区表达。
- 抽屉打开时显示遮罩并锁定页面滚动；点击遮罩、菜单项或按 Escape 关闭。
- 汉堡按钮维护 `aria-controls`、`aria-expanded` 和可读标签。
- `max-width: 700px` 时配置单列、按钮可换行、统计双列、历史记录纵向排列；表格保持横向滚动。
- 移动端 Tab 文案保持单行不折行，空间不足时 Tab 列自身横向滚动，汉堡与主题按钮固定可见。
